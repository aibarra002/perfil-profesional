# Portafolio de Carolina Ibarra

## Cómo usarlo
1. Abre esta carpeta en Visual Studio Code.
2. Abre `index.html` en tu navegador.
3. Para poner tu fotografía, guarda tu foto en la carpeta `assets` con el nombre `foto-carolina.jpg`. La página la mostrará automáticamente en el espacio de perfil.
4. Si todavía no agregas tu foto, aparecerá una ilustración provisional.
5. Edita `index.html` para actualizar tu descripción, habilidades y enlaces.

## Archivos
- `index.html`: estructura y contenido.
- `styles.css`: diseño adaptable y colores.
- `script.js`: menú móvil y año automático.
- `assets/`: fotografía de perfil y recursos visuales.

El proyecto está hecho con HTML, CSS y JavaScript sin frameworks.
